# Origem dos elementos visuais

Banner, cards e composição dos badges foram criados para este perfil em SVG, sem scripts ou fontes externas. A animação do banner respeita a preferência de movimento reduzido.

Os glifos Python, Django, PostgreSQL, HTML5, CSS, JavaScript, Git, Linux, GitHub Actions e GitHub vêm do [Simple Icons](https://github.com/simple-icons/simple-icons/tree/1089fb7d2bf0e323f834c205ab76265005a6d5e8/icons), commit `1089fb7d2bf0e323f834c205ab76265005a6d5e8`, sob [CC0 1.0](SIMPLE-ICONS-LICENSE.md).

O globo é um desenho geométrico próprio. O botão LinkedIn usa apenas texto. Marcas pertencem aos respectivos titulares; sua presença identifica tecnologias e destinos de contato, sem sugerir parceria ou endosso.

Todos os elementos exibidos no README são servidos por este repositório. Não há contadores de visitantes, gráficos de produtividade ou chamadas a serviços externos de geração de badges.
